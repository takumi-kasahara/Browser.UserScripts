# Project Guidelines

This project is a collection of Greasemonkey user scripts that automate and enhance web browsing on popular sites. The project uses modern JavaScript (ES modules) with esbuild for bundling and maintains a modular architecture for code reuse.

## Overview

1. `src/` directory: Contains all source code
   - `src/modules/`
     - Reusable utility functions
   - `src/scripts/`
     - Individual user script files (`*.user.ts`)
2. `dist/` directory: Generated during build process
   - Contains built user scripts ready for Greasemonkey installation
   - Generated by `npm run build:gm`
3. `pages/` directory: Web-based distribution
   - Contains the installation page with download links
   - Generated by `npm run build:page`

## Workflow

### Available Commands

- `npm run build:gm`
  - Bundles and processes user scripts with metadata headers
- `npm run build:zip`
  - Creates a zip archive of all scripts
- `npm run build:page`
  - Generates the installation HTML page
- `npm run build`
  - Runs `build:*` sequentially

### Key Tooling

- esbuild: Fast JavaScript bundler
- adm-zip: Zip archive creation
- ESLint: Code linting (configured via `eslint.config.mjs`)
- Node.js ES modules: Uses `"type": "module"` in package.json

## File Naming Conventions

- User scripts must end with `.user.js`
- Names should be descriptive and indicate the site or functionality
- Use Title Case for readability

## When Adding New User Scripts

1. Create the script in `src/scripts/` with `.user.js` extension
2. Import utility modules from `src/modules/` as needed
3. Add Greasemonkey metadata with proper @match patterns
4. Use JSDoc comments for parameters and return types
5. Export utility functions where possible
6. Run `npm run build` to verify bundling succeeds
